# Villa Serenity Design

Θέλω το design του website / landing page να ταιριάζει στις φωτογραφίες που σου επισυνάπτω. 

Create a premium, elegant, high-converting one-page landing page for a rental villa called “Ekaterini VIP Villa”.

The landing page must be designed primarily in Greek, with a language switcher for English (EL / EN). Greek should be the default language.

The goal of the page is:
1. To clearly present the villa, its spaces, amenities, and experience.
2. To help the visitor immediately understand what the villa offers.
3. To drive direct booking inquiries through a booking/contact form.
4. To feel premium, trustworthy, warm, and not generic or “AI-looking”.

STYLE / DESIGN DIRECTION:
- Premium Mediterranean villa aesthetic
- Clean, elegant, minimal but rich visual presentation
- Use a warm luxury hospitality style
- White / off-white base with soft beige / sand / olive / deep blue accents
- Large beautiful sections, refined spacing, modern rounded cards
- Sophisticated typography with strong readability in Greek
- Mobile-first responsive design
- The page should feel like a boutique villa / luxury accommodation landing page
- Use the real villa photos throughout the page in a visually strong way
- Avoid generic stock visuals
- The design should feel polished, premium, and conversion-focused

PAGE TYPE:
- One-page landing page only
- Sticky header navigation that scrolls to sections
- Sections should be clear and visually separated
- Include a sticky “Κάντε Κράτηση” button
- On mobile, make booking CTA always easy to access

MAIN MENU (one-page scroll navigation):
- Αρχική
- Η Βίλα
