## Στόχος
Να μπορείς να μπαίνεις σε μια προστατευμένη σελίδα διαχείρισης (admin) του site και να μπλοκάρεις/ξεμπλοκάρεις ημερομηνίες στο ημερολόγιο, ώστε όταν κλείνεις κράτηση τηλεφωνικά να μη φαίνονται πια διαθέσιμες για online κράτηση.

## Τι θα φτιάξω

### 1. Σύστημα σύνδεσης (Auth)
- Ενεργοποίηση email/password login μέσω Lovable Cloud
- Σελίδα `/auth` για σύνδεση
- Ρόλος `admin` (πίνακας `user_roles`) — μόνο εσύ θα έχεις πρόσβαση
- Θα σου εξηγήσω πώς να φτιάξεις τον δικό σου admin λογαριασμό μετά

### 2. Βάση δεδομένων
- Νέος πίνακας `blocked_dates` (ημερομηνία, λόγος π.χ. "Τηλεφωνική κράτηση", ποιος το πρόσθεσε)
- RLS: όλοι διαβάζουν (για να ξέρει το site ποιες μέρες είναι μπλοκαρισμένες), μόνο admin γράφει/σβήνει
- Οι υπάρχουσες εγκεκριμένες κρατήσεις (`bookings` με status=confirmed) θα μετράνε κι αυτές ως πιασμένες μέρες

### 3. Admin σελίδα `/admin` (προστατευμένη)
- Ημερολόγιο σε μεγάλη προβολή
- Κλικ σε ημέρα → μπλοκάρισμα (με προαιρετική σημείωση) ή ξεμπλοκάρισμα
- Επιλογή εύρους ημερομηνιών (από–έως) για μπλοκάρισμα πολλών ημερών μαζί (π.χ. 5ήμερη τηλεφωνική κράτηση)
- Λίστα με τις μπλοκαρισμένες περιόδους και κουμπί διαγραφής
- Οπτική διάκριση: μπλοκαρισμένες από εσένα vs από online confirmed κρατήσεις

### 4. Σύνδεση με το public booking flow
- Στη φόρμα κράτησης της βίλας, το date picker θα δείχνει τις μπλοκαρισμένες μέρες ως μη διαθέσιμες (γκριζαρισμένες, δεν επιλέγονται)
- Έλεγχος και server-side κατά την υποβολή, ώστε να μην περνάει κράτηση σε πιασμένη μέρα

### 5. Είσοδος διαχειριστή
- Διακριτικός σύνδεσμος "Admin" (ή απλά πηγαίνεις στο `/admin`) — αν δεν είσαι συνδεδεμένος σε στέλνει στο `/auth`

## Τεχνικές λεπτομέρειες
- `blocked_dates`: `date` (unique), `note`, `created_by`, `created_at`
- `user_roles` + security-definer function `has_role()` (best practice, αποφεύγει RLS recursion)
- Availability check μέσω `createServerFn` που ενώνει `blocked_dates` + confirmed `bookings`
- Το date range picker θα χρησιμοποιεί το υπάρχον `src/components/ui/calendar.tsx`

## Ερώτηση πριν προχωρήσω
Θέλεις να μπορείς να μπλοκάρεις **εύρος ημερομηνιών μαζί** (από–έως, ιδανικό για πολυήμερες τηλεφωνικές κρατήσεις) ή **μία-μία ημέρα** με κλικ; Προτείνω και τα δύο, αλλά θέλω επιβεβαίωση.
